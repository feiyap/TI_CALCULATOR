# 其他规则

## 经验值

用途：买属性（当前属性×1 XP/点）、技能（见技能概述）、专业（1 XP）、专长（等级×3）、部分特殊能力、自学。

XP 减免类能力必须自身用 XP 习得才能用，减免至多降到 1，不会到 0。

发放：每场或每影片由 ST 按表现给。书中有固定分配与动态分配两套；单部影片建议 25–35（均 30）。详见 `经验值规则`。

## 基因锁

只有轮回者有；影片原生生物不能开锁。解锁检定是自然骰。

触发（队友误伤/有意行为不能开锁；失去意识不满足；不可避免代价不满足；主神空间原则上不能用非 XP 方式解锁）：

1. 实际伤害结算后生命槽全满且最严重为恶性
2. 足以致死的伤害或效果（不含伤势恶化致死）
3. 珍重的人或队友、造人受到致死伤害（ST 按 RP 裁定；致死只需其在你敏感视觉范围内规则死亡）
4. 因不良状态点数进入严重后果
5. 因不良状态点数进入毁灭后果
6. 全神贯注做非常紧急且重要的事（ST 选开）

每条每场景一次（4/5 按每种负面状态一次）。一次效果触发多条则有多次机会。绝对不可能真死的环境通常无法提升开锁。有持续时间的生物不会满足其他友方的开锁条件（V108）。

首次开启需掷骰的阶（1、2、4 阶）一般有超凡表现，只覆盖该次开锁情境（免伤、免负面、打消致死等），可回溯时点。

一阶被动：极度危险时掷 1D10，10 或以上成功；每成功一次下次 +1（熟练度）；已开启后每部影片结束熟练度 +1。主动开启与更高阶读 `基因锁规则` 全文，禁止凭印象简述二阶以上数值。

## 超凡神圣

见 `超凡神圣`。V108 允许传道化身融合入本体。

## 环境

地形：森林、沼泽、丘陵、山脉、沙漠、冰原、平原、水中/水下。另有天气、温度、其他险情。困难地形：移动 1 米耗 2 米移动力，不能冲锋。V108 削弱龙卷风，卷入效果从定身改为无法移动。

## 零散规则

`一些零散规则`：V108 明确减少类效果通用下限为 1；职能减耗与其他减耗不叠加；良好机动性必须至少移动 1 米以免坠落；主动效果规则有补充。

## 特殊兑换 / 造人 / 造物 / 自学 / 撰写

各有专页。造人：V108 调整了减少/增大体积调整的购买限制。造物：区分修复残骸与修复受损物品。自学：XP 混合支付可以锻炼。撰写：专长价格有回修。
