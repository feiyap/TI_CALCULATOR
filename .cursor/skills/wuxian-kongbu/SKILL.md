## 查询流程（必须）

处理任何规则问题，按此顺序，不得跳过：

1. **定位主题**：用下表把问题归到章节，先读对应蒸馏文件。
2. **检索原文**：在 skill 目录执行

```bash
python scripts/search_rules.py 关键词1 关键词2
python scripts/search_rules.py --list 过滤词
python scripts/search_rules.py --file 页名
```

脚本会把 UTF-8 结果写入 `_last_search.md`。终端若乱码，用 Read 打开该文件。

3. **阅读命中页**：用 Read 打开 `corpus/页名.txt`。条目级资源（某血统、某专长、某武器）必须读该页全文，蒸馏摘要不能替代。
4. **冲突处理**：同一主题多页时，以【规则相关】正文为准；资源页只在自身范围内有效。术语以 [terms.md](terms.md) 与 `corpus/规则术语解释.txt` 为准。V108 热修改动见 `corpus/2.5R_V108.txt`。
5. **作答格式**：先给可用结论，再写依据页名。房规（HR）仅在用户/ST 已声明时采用。

不要把全部语料读进上下文。一次检索不够就换更短关键词或 `--or`。

## 世界观（极简）

- ST（story teller）主持世界；PC 为玩家角色。规则与 ST 常识冲突时，ST 可立房规；PC 可不接受。
- 被选者进入**主神空间**，称为轮回者。约每 10 天进入以影视/游戏/动漫为蓝本的**影片**求生。第一场影片的人叫「新人」，存活后成为轮回者。
- 同一主神空间最多 20 人，构成同一轮回小队。个人房间上限 27 立方千米；未用分数兑换的东西原则上带不出房间/影片。
- 手表提供听说语言转换（不提供读写）。详情：`corpus/主神空间.txt`。

## 核心判定（极简）

采用 **D10 成功数**。DP（dice pool）通常 = 属性 + 技能 ± 调整。骰出 8/9/10 各计 1 成功；默认 **10 加骰**（可再掷，连 10 继续）。加骰最低为 8。

- **竞争**：固定 DC 或「越高越好」（攻击、先攻、举重）。
- **对抗**：DC = 对方当次成功数；平手比机运骰。
- **附加成功**：掷骰有效成功数 > 0 才加入。属性 6 起每 5 点 +1。技能 5/7/9/11/13/15 各 +1（最多 6）。附加成功不能把失败变成成功。
- **自然骰**（机运、基因锁解锁等）：无加骰、不受普通加减值；针对「判定」的效果默认无效。
- 小数判定默认向下取整。乘法多个乘数合并为「额外乘数各 -1 后加到第一个」；速度计算是加减后乘除的例外之一。

完整条文：[core-checks.md](core-checks.md) 与 `corpus/核心规则.txt`。

## 人物卡六段

概念 / 属性 / 技能 / 专长 / 衍生属性 / 能力。

通用建卡 **70 XP**：属性 9–30、技能 15–45、专长 15–45，且技能不超过 `70-属性`，专长花光剩余。属性底 1、建卡上限 5；技能底 0、建卡上限 3（0→1 建卡只花 1 XP）。另得 3 个专业。

九属性：力量/敏捷/耐力（生理），智力/感知/决心（心智），风度/操控/沉着（互动）。凡人约 2，人类极限约 5；6 起传奇。传奇点数 `n = (属性-1)/5` 向下取整。

详情：[character.md](character.md)。

## 战斗与时间（极简）

时间：现实单位；抽象单位（回合≈6 秒、轮、场景/遭遇、影片）；战斗动作（自由 / 迅捷 / 移动 / 标准 / 整轮）。每轮通常 1 标准 + 1 移动 + 1 迅捷 + 不限自由（ST 可限自由次数）。

先攻 DP 初始 = 敏捷 + 沉着。未行动过的人物处于无支线措手不及。

生命：完好 / B 冲击 / L 严重 / A 恶性。无完好则昏迷；无完好且最坏为 A 则伤势恶化。物体不区分 BLA。

伤害流程不可逆，分攻击方 → 防御方 → 结算。命中 ≠ 造成伤害 ≠ 实际伤害。关键字只有：豁免、吸收、抵消、转化、减免、忽略。

详情：[combat.md](combat.md)。

## 资源与等级

兑换分血统、改造、瞳术、能力组、技艺、能量、物品、捆绑包。本质四种：自然、科技、特异、魔幻（后两者为超自然）。支线等级：无支线 / D / C / B / A / S（可再升 SS…）。免疫只挡「产生该效果的资源支线等级及以下」。

查具体条目：先 `--list` 名称，再 `--file` 打开 `corpus/` 对应页。不要用训练数据里的同名能力替代书中条目。
