# 资源目录导航

资源正文全部在 `corpus/`，本页只指路。查条目步骤：

```bash
python scripts/search_rules.py --list 名称片段
python scripts/search_rules.py --file 页名
python scripts/search_rules.py 名称 关键词
```

完整树状目录见 [toc.md](toc.md)「资源相关」一节。

## 大类

| 大类 | 结构要点 | 入口页举例 |
|---|---|---|
| 血统 | 一次性 / 光明 / 黑暗 / 普通 / 特殊；再按有无能量、有无技能树分 | `亚维人` `血族` `赛亚人` `大能转世` |
| 改造 | 一次性（含恶魔果实等）/ 无能量无树 / 无能量有树 / 有能量无树 / 有能量有树 | `橡胶果实` `金刚狼` `人机改造总纲` |
| 瞳术 | 一次性与成长瞳 | `写轮眼` `白眼` `直死魔眼` |
| 能力组 | 近战（武器/肉搏）/ 远程 / 施法 / 其他 / 复合（卢恩、DNF 等） | 各能力组首页 |
| 技艺 | 技巧、心法、身法、护身劲、组合技；技巧下再分近战/远程/施法/其他 | `组合技总纲` `超魔技巧` |
| 能量 | 总纲 + 各能量池 | `能量池总纲` `内力` `魔力` |
| 物品 | 载具、无人机、基本兑换、科技/魔幻/特异、改造 | 按等级与本质分页，页内多条目 |
| 捆绑包 | 独立类型 | `总述` 及各包页面 |

## 物品分页习惯

同一页往往列出一整级（如 `D级枪炮`、`C级奇物`）。搜具体武器名用 AND 关键词；命中后 Read 该页，不要只看摘要。

本质：自然、科技、特异、魔幻。科技无效影片只停用科技物品。

## 能量池

分通用（可标东方/西方）与特殊。按属性架构分生理/心智/互动系。双属性池在前提上视为同时满足两类，对抗时对方也视为满足。同修限制见 `能量池`。获得方式：直购、随资源附送、晋级。当前能量不足则不能支付；减少能量不会降到负。

## 查询注意

- 同名资源（如两个「狂战士」）TOC 里文件名可能是 `狂战士.htm` 与 `狂战士1.htm`，必须打开确认。
- 「变身状态」等未进入规则术语的词只在该资源页有效。
- 捆绑包不能被「只指向血统」或「只指向能力组」的效果随便瞄准，除非包内全是该类型。
- 新增于 V108 的资源清单见 `corpus/2.5R_V108.txt`「新增资源」。
